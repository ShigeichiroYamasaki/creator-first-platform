# Global Protocol Invariants

These invariants apply across Creator First Platform
unless explicitly superseded by an approved higher-level rule.

## Identity

1. Wallet Address MUST NOT be treated as a unique human identity.

2. Account, Wallet, Legal Identity and Governance Identity
   MUST remain logically distinct concepts.

## Governance

3. Token holdings MUST NOT directly determine
   Protocol Governance power.

4. Governance Members MUST derive legitimacy from
   Creator or User communities.

## Privacy

5. Personal information MUST NOT be stored
   on a public blockchain.

6. Detailed individual listening history MUST NOT be
   publicly exposed on-chain.

## Rights

7. Creator registration MUST NOT be treated as proof
   of Rights Ownership.

8. Unverified Rights Claims MUST NOT be treated
   as Verified Rights.

9. Disputed Rights MUST NOT be automatically distributed
   as if the rights state were settled.

## Usage

10. Unverified Usage MUST NOT be used
    for normal Creator Distribution.

11. The same Usage Event MUST NOT be counted twice.

## Distribution

12. Distribution calculations MUST be reproducible
    from the same finalized inputs and policy version.

13. Platform operators MUST NOT arbitrarily remove funds
    from a finalized Creator Distribution Pool.

## Protocol Evolution

14. Important protocol behavior changes MUST be traceable
    to an ADR, accepted governance decision or specification change.

15. Historical protocol versions MUST remain auditable.
