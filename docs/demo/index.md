# 無償版運用実験

将来の音楽サービスを実際に試し、参加者の意見をもとに改善するための実験です。実際のお金や作品は使いません。

::: warning 参加には事前登録が必要です
参加申請が承認されると、登録用メールが1通届きます。
:::

## 参加の流れ

1. 上から参加する立場を選び、表示名とメールアドレスを送ります。
2. 承認後に届くメールを開き、画面の案内に従って登録します。
3. 登録完了後、音楽サービスまたは音楽クリエータ活動を試します。
