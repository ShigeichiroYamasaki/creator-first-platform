# 無償版運用実験

このデモは、将来の音楽サービスを本番公開する前に、**音楽を楽しむ人と音楽クリエーターが実際に試して改善点を見つける公開実験**です。

::: warning 参加には事前登録が必要です
公開実験は、申請、メール確認、運営の承認を終えた実験参加者だけが利用できます。募集期間中は各体験ページから申請できます。受付サーバが停止中または募集期間外の場合は送信できず、画面にその旨を表示します。
:::

## 事前登録で伝える情報

募集期間中に体験ページの申請欄から、次の情報だけを送ります。

- 公開実験で使う表示名（本名でなくても構いません）
- 招待メールを受け取るメールアドレス
- 「音楽リスナー」「音楽クリエータ」「両方」のうち希望する立場
- 募集ごとに案内された確認事項への回答

::: danger 事前登録で送らないもの
仮想通貨ワレットのアドレス、パスワード、秘密鍵、復旧用の単語列、本人確認書類、銀行情報、実在作品、未公開音源は送らないでください。運営から求めることもありません。
:::

## 申請後に届くメール

最初にメールアドレス確認メールが届きます。リンクを開くまで審査は始まりません。確認後は運営が申請を審査し、承認された場合に招待メールが届きます。

## 招待メールが届いたら

1. 送信元と、案内されていた実施内容が一致することを確認します。
2. メールの「参加登録を始める」リンクを開きます。
3. 画面に表示される表示名、体験区分、期限を確認します。
4. 「仮想通貨ワレットを開く」を押し、画面の案内に従います。
5. 利用条件を確認して登録します。
6. 「登録できました」と表示されたら、運営から利用開始の連絡が届くまで待ちます。

招待メールのリンクは、本人が一度だけ使用する期限付きリンクです。他の人へ転送しないでください。メールを受け取っただけでは参加登録は完了していません。

## はじめて仮想通貨ワレットを使う方へ

仮想通貨ワレットは、実験の操作を本人が行ったことを確認するために使います。本デモでは、オレンジ色のキツネが目印の **MetaMask（メタマスク）** を使用します。

[仮想通貨ワレットの準備を画像付きで確認する →](/demo/metamask-amoy-setup)

この実験では実際のお金を購入する必要はありません。操作に必要な練習用の残高は、事前登録した実験参加者へ運営が必要な範囲で用意します。

## この実験で確定しないこと

- 本番サービスへの入会、契約、報酬または将来の利益
- 本人、著作権、原盤権または配信許諾の確認
- 実際のお金の支払い、返金または換金
- 議員、投資家、権利者または受取人としての本番資格

詳しい開発状況や技術資料は[現在の状況](/status)に分けて掲載しています。実験参加者は、このページと各体験画面の案内だけで進められます。
