# ユーザ院議会

ユーザの利便性、価格、プライバシー、発見およびコミュニティの観点からCFPを審議し、音楽クリエータ院議会とは独立して承認投票を行う入口です。両院の結果は合算せず、両方が承認した場合だけ次の検証段階へ進みます。

[音楽クリエータ院議会を開く](/demo/creator-house) · [両院の統合画面を開く](/demo/governance)

<ClientOnly>
  <TestnetGovernanceDemo focus-house="user" />
</ClientOnly>

この公開画面はテストネット専用です。公開マニフェストで検証済みの議員登録アダプターを使い、有効なmockJPYCサブスクリプションを持つウォレットが公開デモ会期1の開始前に自己登録できます。この簡略資格は、検証可能な抽選、本人性、一人性、秘密投票、正式な議会運営または法的承認を成立させるものではありません。

![ユーザ院議会ガバナーSBTのテスト用画像](/images/user-house-governor-sbt.png)

[ユーザ院議会ガバナーSBTの公開メタデータJSON](/sbt/user-house-governor.json)は、この画像をHTTPS URLで参照します。これは将来の会期別・失効可能な議員資格SBT用メタデータ原案であり、現在デプロイ済みのSBTコントラクトが発行するトークンではありません。
