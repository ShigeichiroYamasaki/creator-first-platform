# 音楽クリエータ活動の体験を始める

公開実験で使う仮の活動名、音楽の分野、活動方法を登録します。入力内容は、このブラウザの現在のタブを閉じるまでだけ保存されます。

::: warning 招待登録と初回POL受領を終えた方が対象です
招待ページに「運営による準備が完了しました」と表示された後に進んでください。まだの方は[音楽クリエータの実験参加準備](/demo/creator-participation)へ戻ります。
:::

## 入力するもの

- 公開実験だけで使う仮の活動名
- おおまかな音楽の分野
- ソロ、グループなどの活動方法

::: danger 入力しないもの
本名、住所、連絡先、本人確認書類、契約書、権利資料、税務・銀行情報、パスワード、秘密鍵、仮想通貨ワレットのアドレス、実在作品または未公開音源は入力しないでください。
:::

この登録は、事前申請や審査とは別の、活動体験用の仮プロフィールです。本人、作品の権利、配信許可または報酬の受取資格を確認するものではありません。

登録後は[音楽クリエータの活動体験へ進む](/demo/creator-workspace)ことができます。
