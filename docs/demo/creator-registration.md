# 音楽クリエータの参加登録

公開実験で使う仮の活動名、音楽の分野、活動方法を登録します。入力内容は、このブラウザの現在のタブを閉じるまでだけ保存されます。

::: warning 招待メールを受け取った方が対象です
運営から音楽クリエータとして招待され、参加登録を終えた実験参加者が利用します。まだ招待を受けていない方は、[事前登録から参加までの流れ](/demo/)を確認してください。
:::

## 入力するもの

- 公開実験だけで使う仮の活動名
- おおまかな音楽の分野
- ソロ、グループなどの活動方法

::: danger 入力しないもの
本名、住所、連絡先、本人確認書類、契約書、権利資料、税務・銀行情報、パスワード、秘密鍵、仮想通貨ワレットのアドレス、実在作品または未公開音源は入力しないでください。
:::
