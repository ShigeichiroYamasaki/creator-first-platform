# 音楽クリエータの実験参加準備

このページは、申請から審査、招待登録、操作用POLの受領までを行う場所です。作品や活動情報の登録はここでは行いません。

## 準備が完了するまで

1. 仮の活動名と連絡用メールアドレスで申請します。
2. 確認メールのリンクを開き、運営の審査を待ちます。
3. 承認メールの招待リンクを開き、本人の仮想通貨ワレットを登録します。
4. 運営が参加資格と初回POLを準備します。
5. 招待ページに「運営による準備が完了しました」と表示されたら、[音楽クリエータの活動体験](/demo/creator-registration)へ進みます。

::: danger 実在する作品や権利資料を送らないでください
この申請では、本名、未公開音源、契約書、権利資料、銀行情報、仮想通貨ワレットのアドレスは送信しません。
:::
