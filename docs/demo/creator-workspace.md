# テスト音楽クリエーター利用フローデモ

最小の音楽クリエーター利用フローとして、仮名プロフィール登録後にウォレットをPolygon Amoyへ接続し、音楽クリエーターコミットメントと作品の権利自己申告コミットメントを登録できます。

事前登録制の公開実験では、運営が音楽クリエーターのEOAをあらかじめ収集せず、音楽クリエーター役割を付けた一回限りの招待URIを発行します。本人は招待ページで利用するMetaMaskウォレットを選択します。この招待登録は実験参加資格であり、本人確認、音楽クリエーター審査、権利確認または受取人確認を代替しません。

::: warning テストネット専用・権利未確認
プロフィールと作品名は現在のタブだけに保存し、Polygon Amoyにはsalt付きハッシュ、ウォレットアドレス、状態、トランザクションだけを記録します。これは本人確認、権利検証、配信許諾、受取人確認、作品公開または報酬確定ではありません。
:::
