# 音楽クリエータの活動体験

仮の活動名とテスト作品を使い、音楽クリエータとして活動情報を登録する流れを試します。

::: warning 実験参加の準備を先に完了してください
運営から初回POLを受け取った実験参加者が対象です。まだの方は[音楽クリエータの実験参加準備](/demo/creator-participation)へ戻ってください。仮の活動情報は、このページの最初に登録できます。
:::

## この画面で試すこと

1. 仮想通貨ワレットをつなぎます。
2. 自分が活動情報を登録したことを、練習用ネットワークへ記録します。
3. 架空の作品名と権利に関する自己申告を登録します。
4. 登録した内容を確認し、必要であれば取り下げます。

画面に表示される **MetaMask** は仮想通貨ワレット、**Polygon Amoy** は実際のお金を使わない練習用ネットワークです。「コミットメント」は、入力内容そのものを公開せず、その時点で申告したことを後から確認できる形で記録する操作を意味します。

::: danger 実在作品や権利資料を使わないでください
仮の活動名と架空の作品だけを使用します。本名、未公開音源、契約書、権利資料、銀行情報、秘密鍵または復旧用の単語列は入力しないでください。
:::
