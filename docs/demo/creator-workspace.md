# テスト音楽クリエーター利用フローデモ

最小の音楽クリエーター利用フローとして、仮名プロフィール登録後にウォレットをSepoliaへ接続し、音楽クリエーターコミットメントと作品の権利自己申告コミットメントを登録できます。

::: warning テストネット専用・権利未確認
プロフィールと作品名は現在のタブだけに保存し、Sepoliaにはsalt付きハッシュ、ウォレットアドレス、状態、トランザクションだけを記録します。これは本人確認、権利検証、配信許諾、受取人確認、作品公開または報酬確定ではありません。
:::
