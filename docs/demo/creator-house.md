# 音楽クリエータ院議会

音楽クリエーターの権利、分配、制作活動および持続可能性の観点からCFPを審議し、ユーザ院議会とは独立して承認投票を行う入口です。両院の結果は合算せず、両方が承認した場合だけ次の検証段階へ進みます。

[ユーザ院議会を開く](/demo/user-house) · [両院の統合画面を開く](/demo/governance)
