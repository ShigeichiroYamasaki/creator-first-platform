# 音楽クリエータ院議会

音楽クリエーターの権利、分配、制作活動および持続可能性の観点からCFPを審議し、ユーザ院議会とは独立して承認投票を行う入口です。両院の結果は合算せず、両方が承認した場合だけ次の検証段階へ進みます。

[ユーザ院議会を開く](/demo/user-house) · [両院の統合画面を開く](/demo/governance)

<ClientOnly>
  <TestnetGovernanceDemo focus-house="creator" />
</ClientOnly>

この公開画面はテストネット専用です。公開マニフェストで検証済みの議員登録アダプターを使い、活動中のテスト音楽クリエーター登録を持つウォレットが公開デモ会期1の開始前に自己登録できます。この簡略資格は、検証可能な抽選、本人性、一人性、秘密投票、正式な議会運営または法的承認を成立させるものではありません。
