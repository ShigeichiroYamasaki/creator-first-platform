# 音楽リスナーとして参加する

このページでは、仮の名前の登録、財布アプリの接続、練習用の月額利用、音楽プレーヤー、好きな音楽クリエーターを応援した証明書を順番に試します。

::: warning 参加には申請と運営の承認が必要です
募集期間中は、このページから実験参加を申請できます。メールアドレスを確認した後、運営が申請を審査します。承認されるまで実験機能は利用できません。
:::

## 操作を始める前の確認

まず仮の名前を登録し、財布アプリを準備します。招待済みでない方は、画面の「実験参加登録を確認」から次の順に進みます。

1. 連絡用メールアドレスを入力して申請します。
2. 届いた「メールアドレスを確認する」リンクを開きます。
3. 運営の審査結果を待ちます。
4. 承認メールの「参加登録を始める」リンクを開き、財布アプリをつないで本人登録します。
5. 運営が練習用残高を準備した後、利用開始の連絡を受け取ります。

申請しただけ、メールを確認しただけ、または承認メールを受け取っただけでは参加登録は完了していません。画面には、現在の段階と次に行うことが表示されます。

財布アプリを初めて使う方は、[画像付きの準備手順](/demo/metamask-amoy-setup)を先に確認してください。

## 画面に出てくる言葉

| 画面の表示 | 意味 |
| --- | --- |
| MetaMask | オレンジ色のキツネが目印の財布アプリ |
| Polygon Amoy | 実際のお金を使わない練習用ネットワーク |
| tJPYC / mockJPYC | 月額利用を試すための、換金できない練習用のお金 |
| POL | 操作を記録するために少量だけ使う、練習用の手数料残高 |
| SBT | 好きな音楽クリエーターを応援したことを示す、他人へ渡せないデジタル証明書 |

これらはすべて実験用で、購入、換金、返金または本番サービスの権利には使えません。

## 進め方

画面内の番号に沿って、上から順番に操作します。次のボタンが薄い色で押せない場合は、その直前の操作が終わっているか確認してください。

1. 個人情報を含まない仮の名前を登録します。
2. 財布アプリをつなぎ、練習用ネットワークへ切り替えます。
3. 未申請なら参加を申し込み、メール確認と運営の承認後に本人登録します。
4. 練習用のお金を受け取り、月額利用を開始します。
5. 短いテスト音をプレーヤーで再生します。
6. 希望する場合だけ、音楽クリエーターを応援した証明書を受け取ります。

::: danger 安全のために守ること
- 本番用の財布や実際のお金を使わないでください。
- パスワード、秘密鍵、復旧用の単語列を入力しないでください。
- 財布アプリの確認画面で、内容がわからない操作は承認しないでください。
- 「資金を追加」と表示されても、実際のお金を購入しないでください。
:::

## この画面だけでは得られないもの

画面上の仮名登録だけで、音楽の利用、財布アプリの接続、月額利用またはデジタル参加証の権利は得られません。それぞれ画面の案内に従った別の操作が必要です。

このデモは、本番アカウント、実際の継続課金、実在楽曲の配信、本人確認または将来の利益を作るものではありません。
