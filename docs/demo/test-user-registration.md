# 音楽サービスを体験する

このページは、審査と招待登録を終え、運営から初回POLを受け取った音楽リスナー向けです。申請と審査はこのページでは行いません。

::: warning 先に実験参加の準備を完了してください
招待ページに「運営による準備が完了しました」と表示され、初回POLを受け取った後に進んでください。まだの方は[音楽リスナーの実験参加準備](/demo/listener-participation)へ戻ります。
:::

## このページで試すこと

1. 招待登録で使ったのと同じ仮想通貨ワレットをつなぎます。
2. 音楽リスナーの利用資格を本人が登録します。
3. mockJPYC（tJPYC）という換金できない練習用のお金を受け取り、月額利用を試します。
4. 短いテスト音を再生します。
5. 希望する場合だけ、音楽クリエータを応援した証明書を受け取ります。

| 表示 | 意味 |
| --- | --- |
| POL | 操作記録の手数料に使う実験用残高 |
| mockJPYC / tJPYC | 月額利用の練習に使う、換金できないお金 |
| SBT | 応援したことを示す、他人へ渡せないデジタル証明書 |

::: danger 安全のために守ること
- 本番用の仮想通貨ワレットや実際のお金を使わないでください。
- パスワード、秘密鍵、復旧用の単語列を入力しないでください。
- 「資金を追加」と表示されても、実際のお金を購入しないでください。
:::
