# 音楽クリエータサービス

まず仮名の音楽クリエータープロフィールを登録し、その後テスト音楽クリエーター利用フローでPolygon Amoy ウォレット、音楽クリエーターコミットメント登録、作品の権利自己申告コミットメントを試せます。

<DemoServiceChoices kind="creator" />

音楽クリエーター作業画面で扱う合成データをプラットフォーム全体の資金と突合する[資金フロー可視化デモ](/demo/treasury-dashboard)も確認できます。

::: warning Test-only境界
プロフィール入力は現在のタブだけ、ウォレットアドレス、コミットメント、音楽クリエーター／リリース ID、状態およびトランザクションはPolygon Amoyの公開情報になります。本人・法人確認、権利検証、音源アップロード、配信公開、報酬計算または支払処理を行いません。
:::
