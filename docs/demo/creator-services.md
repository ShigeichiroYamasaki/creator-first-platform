# 音楽クリエータサービス

まず仮名の音楽クリエータープロフィールを登録し、その後テスト音楽クリエーター利用フローでSepolia Wallet、音楽クリエーターコミットメント登録、作品の権利自己申告Commitmentを試せます。

<DemoServiceChoices kind="creator" />

音楽クリエーター作業画面で扱う合成データをプラットフォーム全体の資金と突合する[資金フロー可視化デモ](/demo/treasury-dashboard)も確認できます。

::: warning Test-only境界
Profile入力は現在のタブだけ、Wallet Address、Commitment、音楽クリエーター／Release ID、状態およびTransactionはSepoliaの公開情報になります。本人・法人確認、Rights Verification、音源Upload、配信公開、報酬計算または支払処理を行いません。
:::
