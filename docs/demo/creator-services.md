# 音楽クリエータとして参加

自分で制作・流通・発信を判断する独立系の音楽クリエータを想定し、音源などの登録、ファンからの応援や交流、収益分配ルールづくりへの参加を試します。現在の公開画面では、実在する音源を送らず、テスト作品の情報だけを使います。

::: warning 最初に事前登録が必要です
募集期間中は「はじめから体験する」の画面から音楽クリエータとして申請できます。メール確認と運営の承認が終わるまで、作品情報の記録などは開始できません。[申請から参加までの流れ](/demo/)も確認してください。
:::

## はじめて参加する方

1. 「はじめから体験する」で仮の活動情報を登録し、参加を申請します。
2. 届いたメール確認リンクを開き、運営の審査結果を待ちます。
3. 承認メールの招待リンクを開き、仮想通貨ワレットをつないで参加登録を完了します。
4. 運営から利用開始の連絡が届いたら、同じ画面で続きを試します。

事前登録やデモでは、実在作品、未公開音源、契約書、権利資料、銀行情報を送らないでください。

## どちらから進みますか

<DemoServiceChoices kind="creator" />

「はじめから体験する」では、仮の活動名とテスト作品を使って登録から順に進みます。「活動画面だけ見てみる」では、操作を行わずに作品管理画面の見本を確認できます。

::: info 権利や報酬は確定しません
この実験は、本人確認、著作権・原盤権の確認、配信許可、作品公開、報酬計算または支払いを行いません。
:::
