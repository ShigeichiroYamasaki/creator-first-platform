# 音楽クリエータサービス

まず仮名のCreator Profileを登録し、その後Creator Workspaceで作品Draftと確認状態を試せます。

<DemoServiceChoices kind="creator" />

Creator Workspaceで扱う合成データをプラットフォーム全体の資金と突合する[資金フロー可視化デモ](/demo/treasury-dashboard)も確認できます。

::: warning Test-only境界
すべて現在のタブ内だけで動く合成デモです。本人・法人確認、Rights Verification、音源Upload、配信公開、報酬計算、Walletまたは支払処理を行いません。
:::
