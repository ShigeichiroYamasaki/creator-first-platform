# 音楽クリエータとして参加

自分で制作・流通・発信を判断する独立系の音楽クリエータを想定した実験です。目的の異なる二つの段階に分かれます。

- **実験参加の準備**：申請、メール確認、運営審査、招待登録、初回POL受領まで
- **音楽クリエータ活動の体験**：POL受領後に、仮の活動情報とテスト作品の登録を試す

::: warning 現在の段階に合うボタンを選んでください
申請や審査中の方は「実験参加の準備」へ進みます。招待ページで初回POLの受領完了が表示された方は「音楽クリエータ活動を体験」へ進みます。
:::
