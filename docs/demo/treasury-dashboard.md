# 資金フロー可視化デモ

サブスクリプション課金やサポーター支援から、音楽クリエーター分配、システム維持、納税、プロモーション、コミュニティ運営までを、**期間中の動き**と**期末時点の残高**に分けて確認する画面です。数値表に加え、期間資金フローと期末ストックの構成をサンキー・ダイアグラムで確認できます。

<ClientOnly>
  <TreasuryFlowDemo />
</ClientOnly>

## 本番実装で突合する正本

| 表示対象 | 主な正本 | 画面での扱い |
| --- | --- | --- |
| 課金・返金 | 決済台帳・法人会計 | 確定状態と証憑参照を付けて期間収入へ反映 |
| コントラクト内資産 | 対象チェーンと確定性Indexer | Asset・Network・Block基準を固定して残高へ反映 |
| 法人管理資産・未収金 | 法人の会計・資金管理 | 会計締めと照合状態を付けて表示 |
| 音楽クリエーター分配 | Distribution Result・支払台帳 | 計算済み、保留、支払指図、支払済みを分離 |
| 税・維持費・Promotion | 法人会計・承認済み予算 | 見積、未払、支払済みを区別 |
| Community予算 | Governance決定・法人会計 | 承認額と執行額を分離 |

::: warning Test-only境界
表示値はすべて固定のMockJPYC合成Fixtureです。実際のウォレット、コントラクト、会計システム、銀行、税務処理とは接続せず、法定の貸借対照表・会計帳簿・税務申告にも該当しません。
:::

設計根拠は[ADR-0013](/adr/ADR-0013-treasury-flow-transparency)と[音楽クリエーター分配仕様](/protocol/specs/creator-distribution)を参照してください。
