# 音楽リスナーとして参加

音楽リスナーの実験は、目的の異なる二つの段階に分かれます。

- **実験参加の準備**：申請、メール確認、運営審査、招待登録、初回POL受領まで
- **音楽サービスの体験**：POL受領後に、練習用のお金で月額利用、再生、応援証明などを試す

::: warning 現在の段階に合うボタンを選んでください
申請や審査中の方は「実験参加の準備」へ進みます。招待ページで初回POLの受領完了が表示された方は「音楽サービスを体験」へ進みます。
:::

::: info 実際のお金や楽曲は使いません
POLは操作手数料用、mockJPYC（tJPYC）は月額利用用の、どちらも実験用です。購入、換金、継続課金または本番サービスへの登録は行いません。
:::
