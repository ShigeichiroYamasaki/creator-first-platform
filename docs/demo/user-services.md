# 音楽リスナーとして参加

音楽リスナーの立場で、音楽サブスクリプションサービスの利用、音楽クリエータの応援、サービス改善や経営への参加などを試します。

::: warning 最初に事前登録が必要です
募集期間中は「はじめから体験する」の画面から申請できます。メール確認と運営の承認が終わるまで、月額利用などの実験機能は開始できません。[申請から参加までの流れ](/demo/)も確認してください。
:::

## はじめて参加する方

1. 「はじめから体験する」で仮の名前を登録し、参加を申請します。
2. 届いたメール確認リンクを開き、運営の審査結果を待ちます。
3. 承認メールの招待リンクを開き、仮想通貨ワレットをつないで参加登録を完了します。
4. 運営から利用開始の連絡が届いたら、同じ画面で続きを試します。

申込時に仮想通貨ワレットのアドレス、パスワード、秘密情報を送る必要はありません。

## どちらから進みますか

「はじめから体験する」では、画面の番号に沿って練習用のお金、月額利用、音楽プレーヤー、応援の証明書を順番に試します。「画面だけ見てみる」では、操作を行わずに音楽サービスの見本を確認できます。

::: info 実際のお金や楽曲は使いません
表示される残高、音楽、音楽クリエーター名、応援の状態はすべて実験用です。購入、換金、継続課金または本番サービスへの登録は行いません。
:::
