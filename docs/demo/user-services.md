# 音楽リスナーとして参加

音楽リスナーの立場で、音楽サブスクリプションサービスの利用、音楽クリエータの応援、サービス改善や経営への参加などを試します。

::: warning 最初に事前登録が必要です
運営から招待メールを受け取っていない方は、まだ実験を開始できません。[事前登録から参加までの流れ](/demo/)を先に確認してください。
:::

## はじめて参加する方

1. 募集案内に記載された方法で事前登録を申し込みます。
2. 運営から届いた招待メールのリンクを開きます。
3. 画面の案内に従って財布アプリをつなぎ、参加登録を完了します。
4. 運営から利用開始の連絡が届いたら、下の「はじめから体験する」へ進みます。

申込時に財布の番号、パスワード、秘密情報を送る必要はありません。

## どちらから進みますか

「はじめから体験する」では、画面の番号に沿って練習用のお金、月額利用、音楽プレーヤー、応援の証明書を順番に試します。「画面だけ見てみる」では、操作を行わずに音楽サービスの見本を確認できます。

::: info 実際のお金や楽曲は使いません
表示される残高、音楽、音楽クリエーター名、応援の状態はすべて実験用です。購入、換金、継続課金または本番サービスへの登録は行いません。
:::
