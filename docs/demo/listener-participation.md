# 音楽リスナーの実験参加準備

このページは、申請から審査、招待登録、操作用POLの受領までを行う場所です。月額利用や音楽再生はここでは行いません。

## 準備が完了するまで

1. 仮の名前と連絡用メールアドレスで申請します。
2. 画面に「運営が申請を確認しています」と表示されたら待ちます。
3. 承認後に届く1通の参加登録用メールを開き、本人の仮想通貨ワレットを登録します。
4. 運営が参加資格と初回POLを準備します。
5. 招待ページに「運営による準備が完了しました」と表示されたら、[音楽サービスの体験](/demo/test-user-registration)へ進みます。

::: info POLと練習用のお金は別物です
POLは実験の操作を記録する手数料用の少量の残高です。月額利用に使う mockJPYC（tJPYC）は、POL受領後のサービス体験画面で受け取ります。
:::
