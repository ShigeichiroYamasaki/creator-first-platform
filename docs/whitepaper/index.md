# Creator First Platform Whitepaper

Creator First Platformは、クリエイターの権利と持続可能な創作活動を中心に据えた音楽配信基盤です。

## 現在の段階

このプロジェクトは現在、ホワイトペーパー策定段階です。

本格的なスマートコントラクト、バックエンド、音楽プレーヤーの実装は、仕様とガバナンスが確定した後に開始します。
