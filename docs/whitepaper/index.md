# Creator First Platform ホワイトペーパー

本文の参加主体と議会名称は、[正規用語表](../terminology.md)に従います。

Creator First Platformは、音楽クリエーターの権利と持続可能な創作活動を中心に据えた音楽配信基盤です。

本書の中心対象は、メジャーレーベルに属さず、制作・流通・マーケティング等の重要判断を自ら行うアーティストダイレクト型の独立系アーティストです。外部の音楽配信代行・著作権管理サービスを利用する場合も、その契約範囲と権利状態を分離して確認します。

## 現在の段階

このプロジェクトは現在、ホワイトペーパーとプロトコルの策定を継続しながら、ローカルモックと公開テストネットで主要な境界を検証する段階です。

テストネット専用スマートコントラクト、利用フロー、音楽プレーヤーおよびゲートウェイモックは部分実装済みです。一方、本番コントラクト、本番決済、権利処理、配信基盤、コミュニティおよび運用ガバナンスは未成立です。本番系はテストネットを昇格させず、[本番サービス全体アーキテクチャ](/adr/ADR-0018-production-service-architecture)に従って独立構築し、レビューと監査を経て段階公開します。

公開済み文書、草案仕様、未実装範囲、専門家確認事項は[現在の状況](/status)にまとめています。
