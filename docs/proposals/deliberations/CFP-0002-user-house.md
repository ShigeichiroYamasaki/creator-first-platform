## 主な論点

- 365日・締切時刻を含まないという条件はユーザが事前確認できる。
- クリックや署名ではなくオンチェーン確定時刻を使うため、締切直前のリレイヤー遅延を説明する必要がある。
- 公開SBTはウォレットと支援対象を関連付けるため、受領を任意とし、公開範囲・Burn・回復を説明する必要がある。
- 金額の大小や先着人数によって資格を変えないことは公平性に資する。
- SBTがサブスクリプション、議決権、投資または音楽の権利を自動付与しないことをUIで明示する必要がある。

## 付帯条件

1. 締切までの残時間、確定待ちおよび一般／初期の最終結果を区別して表示する。
2. SBTを受け取らず一般サポーターとして参加できる選択肢を検討する。
3. 誤判定、ウォレット喪失、失効への異議申立てと回復経路を設ける。
4. 本番前に実在するユーザによるアクセシビリティと理解度テストを実施する。

この記録は自動テスト用の合成証拠であり、実在するユーザ院議会の議決ではない。
