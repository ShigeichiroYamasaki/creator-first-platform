# CFP-0002 憲章適合性レビュー

| 項目 | 内容 |
| --- | --- |
| 対象 | CFP-0002 Revision 1 |
| 評価日 | 2026-08-24 |
| 評価状態 | テストネット用の条件付き適合 |
| 本番効力 | なし |
| 正式審査の停止条件 | 三憲章の独立した正本文書、版、採択手続および審査権者が未確定 |

## 評価結果

| 憲章原則 | 評価 | 理由と条件 |
| --- | --- | --- |
| 音楽クリエーター憲章 | 条件付き適合 | 活動初期からの支援を可視化し、支払額や人気に左右されない。ただし音楽クリエーターが表示・コミュニティ形成へ同意でき、誤った登録日の訂正と異議申立てが必要 |
| ユーザ憲章 | 条件付き適合 | 条件が一律かつ事前説明可能で、既発行階層を遡及変更しない。ただし公開ウォレットとの関連付け、受領同意、Burn、回復、異議申立てを実装する必要がある |
| エコシステム憲章 | 条件付き適合 | 譲渡不能で、資本保有・投資額・支払額を資格や議決権へ変換しない。ただし限定特権が公正性や権利許諾を害さないよう別審査が必要 |

## 憲章上の不変条件

- 初期サポーターSBTは金銭的リターン、株主権、STO権利または自動的な議決権を表さない。
- 一般／初期サポーターのいずれも、サブスクリプションまたは配信権を置換しない。
- 支払額、保有資産、人気、再生数またはフォロワー数を初期資格の条件にしない。
- 同じ音楽クリエーターとユーザの組合せについて、一つの有効資格証明と一つの確定階層だけを認める。
- ポリシー変更によって過去の発行事実を遡及的に書き換えない。

## 形式的限界

現在の三憲章は[ホワイトペーパーのビジョン章](/whitepaper/01-vision)と[ガバナンス章](/whitepaper/07-governance)で原則として説明されているが、独立した正本文書、確定版、採択主体および正式な適合性審査手続は未成立である。このため、本記録はテストネット状態遷移を試すための予備評価であり、「憲章適合が正式に証明された」と表示してはならない。

正式審査では、対象CFP本文ハッシュ、三憲章の各版ハッシュ、少数意見、条件、審査者、利益相反および異議申立て期限を一つの証拠束へ含める。
