# CFP-0002 法務実行可能性レビュー

| 項目 | 内容 |
| --- | --- |
| 対象 | CFP-0002 Revision 1 |
| 評価日 | 2026-08-24 |
| 評価状態 | テストネット用の条件付き実行可能 |
| 法律意見 | 該当しない |
| 本番効力 | なし。日本法に詳しい弁護士、個人情報、消費者、金融、税務の専門家確認が必要 |

## 予備評価

CFP-0002が提案するSBTは、支援時期を表示する譲渡不能・失効可能な資格証明であり、文書上は配当、収益分配、返済、換金請求、株主権、STO権利または自動的議決権から分離されている。この限定された構成はテストネットで制度・コード境界を検証できる。ただし、実際の販売方法、支払、限定特権、広告表示、データ処理および契約内容によって法的評価が変わるため、本番適法性を確定しない。

| 論点 | 条件付き評価 | 本番前に必要な処理 |
| --- | --- | --- |
| 個人情報・プライバシー | 公開ウォレットと支援対象の組合せが特定個人と結び付く場合がある | 利用目的、公開範囲、同意または他の適法な根拠、データ最小化、保存・削除、アカウント対応表へのアクセス制御を確定 |
| 景品・消費者保護 | 無償の表示資格だけなら経済的利益を限定できるが、購読や支払に付随する特典は内容・価額・表示の審査が必要 | 特権追加前に景品類該当性、上限、誤認表示、利用規約、取消し・異議申立てを確認 |
| 金融規制 | SBT単独で投資・収益・償還の権利を設計しない | JPYC決済、STO、金銭的特権、二次流通と組み合わせる前に別の法的分類を確認 |
| 著作権・原盤権 | 初期サポーター資格は音楽の著作権、原盤権または配信許諾を移転しない | SBTメタデータ、画像、限定音源の利用許諾を権利者契約で明示 |
| 契約・表示 | 「1年未満」の条件は365日・上限排他として説明可能 | 登録時刻の正本、締切、ファイナリティ、リレイヤー遅延、失効・Burn・回復を利用規約とUIで一致させる |

## テストネットで通過可能とする条件

- 無価値・償還不可のテストネット資格証明だけを扱う。
- 実名、連絡先、契約書、支払額、詳細な聴取履歴を公開チェーンへ保存しない。
- 金銭的特権、STO、収益分配、著作権または配信権を付与しない。
- 「法務レビュー済み」ではなく「合成証拠による状態遷移テスト」と表示する。
- 本番デプロイの実行マニフェストには、実在する権限者の法律意見・条件・対象法域・有効期限を別途必要とする。

## 結論

テストネットでの技術検証については条件付きで進行可能と評価する。本番提供については未承認であり、特権内容と事業・契約・決済スキームが確定した後に再審査する。
