# 正規用語表

Creator First Platformの公開文書では、参加主体と議会の名称を次のように統一します。

| 英語表記 | 正規の日本語表記 | 用途 |
| --- | --- | --- |
| Creator | 音楽クリエーター | 音楽の創作・制作に実質的に関与する参加者 |
| User | ユーザ | 音楽その他のコンテンツを利用する参加者 |
| Creator House | 音楽クリエータ院議会 | 音楽クリエーターコミュニティを代表する議会 |
| User House | ユーザ院議会 | ユーザコミュニティを代表する議会 |
| Creator Community | 音楽クリエーターコミュニティ | 音楽クリエーターの共同体 |
| User Community | ユーザコミュニティ | ユーザの共同体 |
| Governance Member | ガバナンス議員 | 抽選によって期間限定で選出された議員 |
| Governance Eligible User | ガバナンス適格ユーザ | ユーザ院議会の抽選母集団へ参加できるユーザ |
| Creator Distribution | 音楽クリエーター分配 | 音楽クリエーター・権利者への分配 |
| Creator Rights | 音楽クリエーターの権利 | 音楽クリエーターに関係する権利 |

## 表記上の例外

- `Creator First Platform`はプロジェクト固有名詞として英語表記を維持します。
- SolidityのContract名、関数名、Event名、Role名、JSONキー、仕様ID、要件ID、ファイル名、URLなどの技術識別子は変更しません。
- 英語のProtocol Specificationで使う規範語`MUST`、`MUST NOT`、`SHOULD`、`MAY`は変更しません。
- 初出時に英語を併記する場合も、本文では正規の日本語表記を主表記とします。

この用語表と異なる表記を導入する場合は、意味の違い、適用範囲および移行方法をADRまたはProtocol Specificationへ記録します。
